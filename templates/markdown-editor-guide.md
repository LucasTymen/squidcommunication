# 📝 Guide : Rédiger avec Markdown

**Pour les responsables de communication**

---

## 🎯 Objectif

Vous pouvez rédiger vos articles dans n'importe quel éditeur Markdown (Notion, Obsidian, etc.) et coller directement le contenu dans les fichiers `.md` des articles. Le Markdown sera préservé et compatible avec LinkedIn.

---

## ✅ Syntaxe Markdown à Utiliser

### Titres
```markdown
# Titre principal (H1)
## Section (H2)
### Sous-section (H3)
```

### Mise en forme
```markdown
**texte en gras**
*texte en italique*
```

### Listes
```markdown
- Point 1
- Point 2
  - Sous-point 2.1

1. Point numéroté 1
2. Point numéroté 2
```

### Séparateurs
```markdown
---
```

### Citations
```markdown
> Citation importante
```

### Code
```markdown
`code inline`
```

---

## 📋 Workflow Recommandé

1. **Rédiger dans votre éditeur préféré** (Notion, Obsidian, VS Code, etc.)
2. **Utiliser le Markdown** pour structurer votre contenu
3. **Copier le contenu** (avec le Markdown)
4. **Coller dans** `articles/article-X/linkedin/post-01.md`
5. **Le Markdown est préservé** ✅

---

## 💡 Exemple

**Dans Notion** :
```markdown
## Mon article

Voici un **texte important** avec une liste :
- Point 1
- Point 2
```

**Coller dans** `articles/article-1/linkedin/post-01.md` :
→ Fonctionne directement ! ✅

---

## ⚠️ Limitations LinkedIn

- ✅ Gras, Italique, Listes, Titres : Supportés
- ⚠️ Tableaux : Non supportés (convertir en liste)
- ⚠️ Code blocks : Support limité (utiliser `code` inline)
