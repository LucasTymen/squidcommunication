## 🎨 Structure SEO par Article

### Dans `articles-planning.json` :

```json
{
  "seo": {
    "primary_keywords": ["mot-clé 1", "mot-clé 2"],
    "long_tail_keywords": ["long tail 1", "long tail 2"],
    "hashtags": ["#SquidResearch", "#IA", "#B2B"],
    "meta_title": "Titre optimisé SEO (50-60 caractères)",
    "meta_description": "Description optimisée (150-160 caractères)",
    "slug": "article-slug-seo-friendly",
    "tags": ["tag1", "tag2", "tag3"]
  }
}
```

### Densité Mots-clés

- **Primaire** : 2-3 fois dans le texte
- **Long-tail** : 1-2 fois naturellement
- **Hashtags** : 3-5 par post, toujours inclure #SquidResearch

## 📈 Optimisation Contenu

### Titres Articles

- **Longueur** : 50-60 caractères
- **Structure** : Mot-clé principal + bénéfice + chiffre si possible
- **Exemple** : "Gain de temps candidature : 93% avec SquidResearch"

### Descriptions

- **Longueur** : 150-160 caractères
- **Structure** : Problème → Solution → Bénéfice
- **Exemple** : "Réduisez votre temps de candidature de 93% avec notre algorithme de matching IA. Automatisez prospection B2B et enrichissement contacts."

### Corps Article

- **Mots-clés primaires** : 2-3 fois (titre, intro, conclusion)
- **Long-tail** : 1-2 fois naturellement
- **Densité** : 1-2% max (éviter keyword stuffing)
